Selected Work

Featured project

PulseSearch

A real-time, AI-native search system over a live data firehose. Change data capture streams every row change from MySQL through Debezium + Kafka into Elasticsearch, served as hybrid BM25 + vector search and a grounded RAG assistant on a local LLM — the whole stack runs on Docker Compose with Prometheus/Grafana SLOs.

  • Effectively-once indexing on at-least-once delivery via version-guarded upserts, replayable backfill & dead-letter isolation
  • Hybrid retrieval: BM25 + kNN fused with Reciprocal Rank Fusion, with per-hit rank provenance
  • Grounded RAG with citations, freshness guarantees, and sub-second CDC-to-searchable latency tracked in Grafana
